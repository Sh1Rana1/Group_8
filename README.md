# VoltDorm OS 校园宿舍水电管理系统

VoltDorm OS 是一个校园宿舍水电监测与预付费管理系统，包含管理员端、学生端、登录注册系统以及本地数据持久化后端。

## 主要功能

### 管理员端

- 查看校园总用电量、总用水量和能耗统计
- 查看学生、宿舍、电表及楼层直饮水表
- 查询电表实时功率、用电量、账户余额和供电状态
- 通过 NB-IoT 模拟下发拉闸、合闸、开阀和关阀指令
- 查看注册学生产生的用电、用水及通知数据
- 学生注销账号后，管理员端自动移除对应学生及空宿舍

### 学生端

- 查询电费余额、实时功率和用电明细
- 在线充值并查看充值记录
- 接收余额、欠费和违规用电通知
- 查询饮水余额与扫码取水记录
- 模拟用电、饮水充值及扫码取水，方便演示系统联动
- 删除通知、退出登录及注销账号

## 运行环境

- Node.js 18 或更高版本
- Chrome、Edge 或其他现代浏览器

本项目后端仅使用 Node.js 内置模块，不需要执行 `npm install`。

## 启动方式

在项目根目录打开终端，然后运行：

```bash
node server.js
```

终端出现以下信息即表示启动成功：

```text
VoltDorm server running at http://localhost:3000
```

随后通过浏览器访问：

[http://localhost:3000/login.html](http://localhost:3000/login.html)

请不要直接双击打开 HTML 文件。登录、注册、账号注销和跨端数据同步功能都依赖后端服务。

如果端口 `3000` 已被占用，可以指定其他端口。

Windows PowerShell：

```powershell
$env:PORT=3001
node server.js
```

macOS 或 Linux：

```bash
PORT=3001 node server.js
```

然后访问对应地址，例如：

```text
http://localhost:3001/login.html
```

## 管理员账号


管理员账号唯一，登录后自动进入管理员界面。

## 学生注册

学生需要先在登录页面选择“学生登录”，然后点击“立即注册”。

注册时需要填写：

- 宿舍楼：学一至学十三
- 楼层：1至5层
- 房间：每层01至14室
- 学生姓名
- 登录账号
- 登录密码，至少6位

新注册学生的电费余额、用电量、饮水余额和用水量初始值均为 `0`。注册完成后，该学生及其宿舍会自动显示在管理员端。

## 数据存储

系统运行后，账号、密码哈希、宿舍及水电数据保存在：

```text
data/db.json
```

用户密码采用加盐哈希保存，不会直接存储明文密码。管理员默认密码除外，它仅作为项目预设登录凭据写在本文档中。

> 将项目上传到公开 GitHub 仓库前，建议不要提交包含真实学生信息的 `data/db.json`。可以删除该文件，后端会在下次启动时自动创建仅包含默认管理员账号的新数据库。

## 项目文件

```text
├─ login.html          登录与学生注册界面
├─ admin.html          管理员端
├─ student.html        学生端
├─ campus-data.js      学生端数据状态与同步逻辑
├─ server.js           Node.js 后端服务
└─ data/
   └─ db.json          本地持久化数据库
```

## 使用流程

1. 运行 `node server.js`。
2. 打开登录页面。
3. 注册学生账号并选择宿舍。
4. 登录学生端，进行电费充值、模拟用电或扫码取水测试。
5. 退出学生账号并使用管理员账号登录。
6. 在管理员端查看对应学生、宿舍及水电数据。

## 注意事项

- 本项目当前适合作为课程设计、功能原型或本地演示系统。
- 登录会话保存在服务器内存中，重启服务后需要重新登录，但注册账号和水电数据不会丢失。
- 管理员端会定时读取后端数据，学生端操作后通常会在数秒内体现。
- 正式部署前应修改默认管理员密码，并补充 HTTPS、数据库、日志、权限控制和请求频率限制等安全能力。
